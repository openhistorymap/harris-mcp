Harris matrices as structured context for language models

harris-mcp is a Model Context Protocol server. It loads stratigraphic matrices from the formats archaeologists use, lets a model query them as a graph, and records every interpretive edit on a changelog a person can audit.

Connect a client Source on GitHub

The split

Deterministic graph work happens on the server; interpretation happens on the model; every edit lands on a changelog.

Server

Parsing, validation, ordering, candidate matching and consistency checks. Deterministic and tested.

Model

Proposes phasings and correspondences from dense, structured reads, not from a screenshot.

Person

Reads the changelog, with a note and an author on every edit, then diffs or reverts.

Quick start

Use the public instance

Any MCP client that speaks SSE can connect. With Claude Code:

claude mcp add --transport sse harris https://harris.openhistorymap.org/mcp/sse

The public instance has no authentication yet and keeps matrices in memory. Do not load unpublished project data there; run your own.

Run your own

docker build -t harris-mcp .
docker run --rm -p 8000:8000 -v "$PWD/data:/data:ro" harris-mcp
# MCP endpoint: http://localhost:8000/mcp/sse   health: GET /

A first session

  1. Open a matrixopen_matrix("/data/fig12") returns a handle, its size, depth and a validation report.
  2. Read it denselydescribe_context(id, "15") returns the unit, its neighbours above and below, its phase and any cross-document links.
  3. Edit with a reasonassign_phase(id, "9", "Phase II", note="C14 LAB-1 fits the lower phase") lands on history.
  4. Savesave_matrix(id, "fig12.hmdp.json") keeps the changelog with the matrix.

Formats

HMDP, an open JSON package defined here, is the pivot: every adapter reads into it and writes out of it.

FormatReadWriteNotes
HMDP .jsonyesyesCanonical and lossless, including the changelog
CSV, XLSXyesyescontexts + relations tables, or an above/below edge list
hm tables (T. S. Dye)yesnoFrictionless datapackage.json or an hm .ini project, a folder or a .zip
HMCX (Harris Matrix Composer)yesnoGraphML inside a zip; phase and period groups become attributes
HMC CSV exportyesnoSemicolon file starting HEADER;, Latin-1 tolerated

Every relation verb is canonicalised: above, below, cuts and fills become edges of a directed acyclic graph from upper to lower unit; equal and contemporary join a union-find class. The original verb stays on the relation.

Reconciling units across records

When two teams record the same deposits, which of their units are the same unit? propose_reconciliation answers in three layers and writes nothing:

  1. CandidatesDescription similarity, compared only between units of the same period and type.
  2. Structural agreementA match scores higher when its matched neighbours sit on the same side, above or below; the matching is refined over a few rounds.
  3. Cycle refusalA match whose merge would put a unit both above and below another is rejected and listed.

The model or a person then records conclusions with assert_correspondence, which reports any contradiction it introduces; check_correspondences audits the whole set.
